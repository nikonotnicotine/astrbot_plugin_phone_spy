astrbot_plugin_phone_spy 新功能使用说明
更新日期：2026-09-03
========================================

本次更新在原有「手机查岗」基础上新增了以下功能：
- 网易云音乐控制（5 个子功能）
- 查看类：电量、微信、支付宝、B站、抖音、淘宝
- 控制类：获取位置、设置闹钟、锁定屏幕

所有功能默认关闭，需要在插件配置页手动开启对应开关，
并在 iPhone 上配置对应的快捷指令自动化，才能正常使用。

========================================
预备知识：三种实现方式的区别
========================================

配置快捷指令时会遇到三种"动作"，先搞清楚区别：

1. App 原生动作（最方便，优先用这个）
   在快捷指令 App 里搜 App 名字（如"网易云"），直接列出来的动作。
   拖进去就能用，不需要任何前置配置。
   网易云、抖音、淘宝都提供了这类动作。

2. URL Scheme
   一串链接，如 orpheus://song/186016/?autoplay=1
   用「打开 URL」动作打开，系统会跳转到 App 对应页面。
   优点是通用，缺点是可能随 App 版本更新失效。

3. Siri 捷径
   注意：名字里带 Siri，但用的时候不需要说话、不需要唤醒 Siri。
   它只是需要你先去 App 里手动"添加到 Siri"注册一次，
   之后就变成快捷指令里的一个普通动作积木。
   现在大部分 App 都直接提供原生动作了，一般用不上这种方式。

本文档优先推荐方式 1，方式 2 作为备选。


========================================
第一步：在 AstrBot 插件配置页开启功能开关
========================================

打开 AstrBot 管理面板 → 插件 → phone_spy → 配置，
按需开启以下开关（不用的功能保持关闭，可节省 AI token 开销）：

【网易云音乐】netease_music 分组
  enable_music_control        总开关，必须开启，子功能才生效
  enable_daily_recommend      播放每日推荐
  enable_personal_fm          播放私人漫游 / 私人 FM
  enable_favorite_playlist    播放红心歌单
  favorite_playlist_id        红心歌单 ID（用原生动作的话留空即可）
  enable_play_pause           播放/暂停
  enable_play_song            播放指定歌曲（AI 自动搜索歌曲 ID）
  auto_screenshot_after_music 操作后自动截图确认（默认关闭）

【查看类】view_actions 分组
  enable_battery              查看手机电量
  enable_wechat               打开微信截图
  enable_alipay               查看支付宝账单
  enable_bilibili             查看 B 站历史
  enable_douyin_msg           查看抖音私信
  enable_douyin_profile       查看抖音个人主页
  enable_taobao_order         查看淘宝订单
  enable_taobao_cart          查看淘宝购物车
  auto_screenshot             查看类是否截图（默认开启，关了功能就没意义了）

【控制类】control_actions 分组
  enable_location             获取当前位置
  enable_alarm                设置闹钟
  enable_lock_screen          锁定屏幕
  auto_screenshot_after_control  控制操作后截图确认（默认关闭）


========================================
第二步：在 iPhone 上配置快捷指令自动化
========================================

打开「快捷指令」App → 底部「自动化」标签 → 右上角「+」→「新建自动化」
→ 选「邮件」→「邮件主题」→「包含」→ 填入对应主题关键词（见下方清单）
→ 取消勾选「运行前询问」→ 添加动作

注意：每个功能对应一个自动化，触发条件是「收到邮件且主题包含 XXX」。

--------------------------------------------
A. 网易云音乐（推荐使用原生动作）
--------------------------------------------

网易云现在提供了原生快捷指令动作，配置非常简单：
在快捷指令里搜索"网易云"，直接拖动作即可，不需要注册 Siri 捷径。
那个 scene 参数是可选的，留空就行。

A1. 每日推荐
  邮件主题包含：ASTRBOT_MUSIC_DAILY
  动作：播放每日推荐（启动 App）[网易云原生动作]
        scene 参数留空

A2. 私人漫游 / 私人 FM
  邮件主题包含：ASTRBOT_MUSIC_FM
  动作：播放私人漫游（启动 App）[网易云原生动作]
        scene 参数留空

A3. 红心歌单
  邮件主题包含：ASTRBOT_MUSIC_FAVORITE
  动作：红心歌单（启动 App）[网易云原生动作]
        scene 参数留空

A4. 播放/暂停
  邮件主题包含：ASTRBOT_MUSIC_PLAYPAUSE
  动作：播放/暂停 [iOS 系统原生媒体控制动作]
        （搜索"播放"即可找到，适用于所有音乐 App）

A5. 播放指定歌曲（插件自动搜索歌曲 ID）
  邮件主题包含：ASTRBOT_MUSIC_PLAY
  动作：
    1. 获取邮件内容（提取「正文」）
    2. 打开 URL（上一步的文本）
  说明：插件会自动搜索歌曲并把 orpheus://song/歌曲ID/?autoplay=1
        这样的链接放在邮件正文里，快捷指令打开即可播放

  备选方案（如果你的网易云版本有「播放特定歌曲」原生动作）：
    可以用那个动作代替上面的"打开 URL"流程，但需要从邮件正文里
    提取歌曲 ID，实现起来更复杂，不如直接打开 URL 简单。

--------------------------------------------
B. 查看类功能（截图回传）
--------------------------------------------

所有查看类功能的快捷指令最后都要加「截图上传」步骤：
  截屏 → 转换图像（格式 JPEG，质量 0.5）→ 获取 URL 内容
  URL：http://你服务器的IP:8080/phone/screenshot
  方法：POST
  请求体：表单
    secret = 你在插件里配的 webhook_secret
    image  = 上一步转换后的图像（类型选「文件」）

B1. 查看手机电量（不需要截图，回传 JSON）
  邮件主题包含：ASTRBOT_BATTERY
  动作：
    1. 获取电池电量（iOS 原生动作，搜索"电池"）
    2. 词典：键 level，值 = 上一步的电量数字
    3. 获取 URL 内容
       URL：http://你的IP:8080/phone/battery
       方法：POST，请求体表单
         secret = 你的密钥
         data   = 上一步的词典（类型选「文本」，会自动序列化为 JSON）

B2. 微信
  邮件主题包含：ASTRBOT_WECHAT
  动作：打开 App（微信）→ 等待 2 秒 → 截图上传（同上）

B3. 支付宝账单
  邮件主题包含：ASTRBOT_ALIPAY
  动作：打开 URL（alipays://platformapi/startapp?appId=20000003）
        → 等待 3 秒 → 截图上传

B4. B站观看历史
  邮件主题包含：ASTRBOT_BILIBILI
  动作：打开 URL（bilibili://user_center/history）
        → 等待 3 秒 → 截图上传

B5. 抖音私信
  邮件主题包含：ASTRBOT_DOUYIN_MSG
  动作（推荐）：打开页面 → 私信消息（抖音原生动作）→ 等待 2 秒 → 截图上传
  动作（备用）：打开 URL（snssdk1128://chat）→ 等待 2 秒 → 截图上传

B6. 抖音个人主页
  邮件主题包含：ASTRBOT_DOUYIN_PROFILE
  动作：打开 URL（snssdk1128://user/profile）→ 等待 2 秒 → 截图上传

B7. 淘宝订单
  邮件主题包含：ASTRBOT_TAOBAO_ORDER
  动作：打开 App（淘宝）→ 等待 3 秒 → 截图上传
  （也可以试试淘宝原生「我的订单」捷径动作，在快捷指令里搜"淘宝"）

B8. 淘宝购物车
  邮件主题包含：ASTRBOT_TAOBAO_CART
  动作：打开 App（淘宝）→ 等待 3 秒 → 截图上传
  （可以试试淘宝原生「购物车」捷径动作）

--------------------------------------------
C. 控制类功能
--------------------------------------------

C1. 获取当前位置（回传 JSON）
  邮件主题包含：ASTRBOT_LOCATION
  动作：
    1. 获取当前位置（iOS 原生动作）
    2. 获取「当前位置」的「纬度」「经度」「街道地址」
    3. 词典：
         latitude  = 纬度
         longitude = 经度
         address   = 街道地址
    4. 获取 URL 内容
       URL：http://你的IP:8080/phone/location
       方法：POST，请求体表单
         secret = 你的密钥
         data   = 上一步的词典（类型选「文本」）

C2. 设置闹钟
  邮件主题包含：ASTRBOT_ALARM
  动作：
    1. 获取邮件内容（提取「正文」，内容是时间如 "07:30"）
    2. 创建闹钟（时间 = 上一步文本，可重复 = 否）

C3. 锁定屏幕
  邮件主题包含：ASTRBOT_LOCK
  动作：锁定屏幕（iOS 原生动作，搜索"锁定"）


========================================
第三步：对 AI 说话
========================================

配置好之后，直接跟 AI 说就行，例如：

  "帮我播放网易云每日推荐"
  "播放周杰伦的晴天"
  "现在在播什么，暂停一下"
  "我的手机电量还有多少"
  "帮我看看我的支付宝账单"
  "我在哪里"
  "帮我设个明天早上七点半的闹钟"
  "锁屏"


========================================
常见问题
========================================

Q：快捷指令没有触发？
A：确认手机网络正常，检查邮件主题关键词是否完全一致（区分大小写）。
   iCloud 邮件通常秒到；如果你用的收件邮箱不是 iCloud，会有 5-15 分钟延迟。

Q：截图上传失败？
A：检查 iPhone 是否和运行 AstrBot 的机器在同一个网络，
   URL 里的 IP 是否正确，端口是否被防火墙放行。

Q：AI 说找不到歌曲？
A：网易云搜索 API 偶发抖动，可以稍等再试，或者加上歌手名更精确，
   例如"播放晴天 周杰伦"。

Q：URL Scheme 打开后 App 没有跳到目标页面？
A：先看看快捷指令里搜 App 名字有没有原生动作，有的话优先用原生动作。
   Scheme 可能随 App 版本更新，可以在 iPhone Safari 地址栏里直接粘贴
   scheme 测试是否能跳转。搜索"App名 URL Scheme"一般能找到最新的。

Q：网易云动作里的 scene 参数要填什么？
A：留空即可。那是网易云内部的埋点字段，不影响功能。

Q：一定要注册 Siri 捷径吗？
A：不需要。网易云等 App 现在都提供原生快捷指令动作，
   在快捷指令里搜 App 名字直接就能找到，拖进去就能用。
