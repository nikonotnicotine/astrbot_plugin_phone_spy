═══════════════════════════════════════════════════════
 开始之前，准备两样东西
═══════════════════════════════════════════════════════

【你的IP】
Windows 命令行输入 ipconfig，找「IPv4 地址」，
形如 192.168.1.100。下面所有 http://你的IP:8080 都换成它。

【你的密钥】
就是插件配置里 webhook_secret 那一栏。
没填就现在填一个 16 位随机字符，比如 a7f3k9m2q5x8w1z4，记住它。

iPhone 要和电脑连同一个 WiFi。


═══════════════════════════════════════════════════════
 建自动化的固定前 6 步（每个功能都一样，先记住）
═══════════════════════════════════════════════════════

1. 打开「快捷指令」App → 底部「自动化」→ 右上角「+」
2. 触发条件列表往下翻，点「邮件」
3. 勾选「发件人」，填插件配置里 smtp_user 那个邮箱地址
4. 勾选「主题」，填该功能对应的主题词（每段里都写了）
5. 打开「立即运行」，关掉「运行前询问」
6. 点「下一步」，进入加动作的界面

后面每段写的「动作 1、动作 2……」就是在第 6 步之后加的。
加完点右上角「完成」。

───────────────────────────────────────────
 播放指定歌曲（想听什么就说什么）
───────────────────────────────────────────
插件开关：enable_play_song
主题填：ASTRBOT_MUSIC_SONG        ← 注意！主题变了

动作 1  搜「从输入中获取文本」，选它

动作 2  搜「打开URL」，选它
        把 URL 输入框里默认的内容【全部删掉】
        然后点输入框，键盘上方会出现蓝色变量按钮，点【文本】

完。歌曲 ID 插件自动查，不用你管。

※ 如果你之前已经建过这个自动化，主题填的是 ASTRBOT_MUSIC_PLAY，
  现在必须改成 ASTRBOT_MUSIC_SONG。
  原因：ASTRBOT_MUSIC_PLAY 是 ASTRBOT_MUSIC_PLAYPAUSE 和
  ASTRBOT_MUSIC_PLAYLIST 的前缀，而 iOS 主题条件是「包含」匹配，
  三个功能会互相误触发。改成 SONG 之后就没有任何前缀关系了。
  改法：快捷指令 App →自动化→点进那条→点最上面的触发条件→改主题词。


───────────────────────────────────────────
 播放预设歌单
───────────────────────────────────────────
插件开关：enable_play_playlist
主题填：ASTRBOT_MUSIC_LIST

【先在插件配置里填歌单】
找到配置项「预设歌单列表」，每行填一个，格式是   名字:歌单ID

  摇滚:2829883282
  睡前:5678901234
  健身:9012345678

名字随便起，你怎么叫 AI 就怎么认。歌单ID 这么拿：
网易云打开那个歌单 → 右上角分享 → 复制链接 → 链接里
playlist?id= 后面那串数字就是。

冒号中英文都行，前后有空格也没事，插件会自己清理。
格式写错的行会被跳过，重载插件后看日志能看到加载了几个。

【再建自动化】
动作 1  搜「从输入中获取文本」，选它

动作 2  搜「打开URL」，选它
        把 URL 输入框里默认内容【全部删掉】
        点输入框，键盘上方点蓝色的【文本】

完。和"播放指定歌曲"的动作一模一样，只是主题词不同。

【怎么跟 AI 说】
  "放我的摇滚歌单" / "来点睡前的" / "放健身歌单"
说部分名字也能匹配上，比如歌单叫"睡前"，你说"睡"也认。
说了不存在的歌单，AI 会把你预设过的名字列出来给你看。

───────────────────────────────────────────
 查看电量
───────────────────────────────────────────
插件开关：enable_battery
主题填：ASTRBOT_BATTERY

动作 1  搜「获取电池电量」，选它

动作 2  搜「文本」，选它
        内容框里粘贴：   {"level": }
        然后把光标点到冒号后面的空格处，
        键盘上方点蓝色的【电池电量】

        ※ 手打的只有  {"level":  和  }
          中间的"电池电量"必须是蓝色变量，不是打上去的四个字

动作 3  搜「URL 请求内容」，选它
        URL 填：http://你的IP:8080/phone/battery
        点动作下方【显示更多】，方法选 POST，请求体选【表单】
        点绿色 + 号，选【文本】
          第一行：键框填 secret    值框填 你的密钥
        再点绿色 + 号，选【文本】
          第二行：键框填 data      值框点一下，键盘上方点蓝色的【文本】

完。两行都是【文本】，这个功能没有文件字段。

※ 如果 AI 说"当前电量 0.85%"，在动作 1 和动作 2 中间插一个
  搜「计算」的动作，把电池电量 × 100。

※ 电量走的是 JSON 回传，不截图，所以插件配置里那个
  「查看类功能是否自动截图」开关对它没有任何影响，
  拨到哪边电量都能用。那个开关只管微信/支付宝/B站/抖音/淘宝。

 获取位置
───────────────────────────────────────────
插件开关：enable_location
主题填：ASTRBOT_LOCATION

动作 1  搜「获取当前位置」，选它
        第一次跑的时候手机会弹窗问定位权限，必须点「允许」

        · 光标点到 latitude 的冒号后面，
          点【当前位置】，选属性【纬度】

        ※ 地址要在双引号里面，经纬度不要引号

动作 3  搜「URL 请求内容」，选它
        URL 填：http://你的IP:8080/phone/location
        【显示更多】→ 方法 POST → 请求体【表单】
        绿色 + 号 → 【文本】
          键框 secret   值框 你的密钥
        绿色 + 号 → 【文本】

 记忆记录（不用建自动化，纯插件配置）
═══════════════════════════════════════════════════════

【这是干什么的】
让 AI 每次操控你手机、每次识图，都在你的记忆插件里
（conversation_logger / romantic_memory）留一条记录。
不开这个的话，AI 看完你手机过一会儿就忘了，因为工具调用
不走正常的对话流程，记忆插件抄不到。

【记忆文件里长这样】
  [系统提示:你操控用户的手机使用了播放指定歌曲功能，播放了《You Like It》 - Omarion]
  [系统提示:你操控用户的手机使用了查看支付宝账单功能，识别截屏结果:今天在瑞幸花了38元……]
  [系统提示:用户发送了一张图片，识别结果:一只橘猫躺在键盘上……]

这些记录你看不到，也不会进 AI 的对话上下文，只有记忆插件抄得到。
两个记忆插件一行代码都不用改。

【配置项】在插件配置的「记忆记录」分组下
  enable                总开关，默认开
  record_tools          记录手机操控（全部18个工具），默认开
  record_user_images    记录你在聊天里发的图片，默认开
                        ※ 每张图会多花一次识图 API 调用
                        ※ 识别在后台跟 AI 回复同时跑，基本不拖慢回复
  private_only          只在私聊里记录，默认开（建议别关）
  max_detail_chars      单条记录长度上限，默认 0 = 不截断
                        嫌记忆文件大就填 200
  template              手机操控记录的格式
  user_image_template   用户图片记录的格式
  user_image_prompt     描述你发的图时给识图模型的提示词
  user_image_timeout    等识图结果的上限，默认 45 秒

识图用的是 vision_api_url 那套配置，不用另外填。
视觉模型没配置的话，图片记录自动跳过，其他照常。


═══════════════════════════════════════════════════════
 整合查岗（默认关闭，不用建新自动化）
═══════════════════════════════════════════════════════

【这是干什么的】
一句暗号，AI 把你配置的项目从头到尾连着查一遍，
最后主动来找你说话。

【为什么不用工具】
工具调用有 120 秒超时上限。连着查四项加上间隔要一两分钟，
必然超时。所以改成：插件只在系统提示里塞一句
「你可以查岗」，AI 想查的时候在回复末尾写个暗号
[查询用户手机APP]，插件抓到就在后台开工。

【⚠️ 全主动】
只有 AI 会触发。你说任何话都不会触发它。

【一次完整流程】假设填了支付宝账单、淘宝购物车、抖音个人主页、位置

  你：在干嘛呢
    ↓ 插件塞一句「你可以查岗」（只这一句，省 token）
  AI：想你呢 [查询用户手机APP]
    ↓ 插件当场剥掉暗号 → 你收到的是「想你呢」
    ↓ 后台开工，你这边回复已经收到了，不卡
  后台：截支付宝 →(5秒)→ 截购物车 →(5秒)→ 截抖音 →(5秒)→ 取位置
    ↓ 三张图打包成一次识图
    ↓ 识图结果 + 位置，问 AI 一次
  AI：你今天在瑞幸又花了38，购物车那双鞋还躺着呢，还在加班？
    ↓ 用平台原生动作发给你

【查岗期间你又发消息了】
默认会把你这条消息按住，等查岗全部结束才交给 AI 回复。
这样 AI 回复时已经知道自己刚看到了什么，不会前后脱节。
最多按住 600 秒（hold_max_seconds），超时直接放行，
不会把你的消息吞掉。插件重载/停用也会立刻放行。

【要填的配置】在插件配置的「整合查岗」分组下

  enable      打开
  features    要查的项目，换行填，按填写顺序查。比如：

                支付宝账单
                淘宝购物车
                抖音个人主页
                位置

              可填这十个：
                当前屏幕  微信  支付宝账单  B站历史  抖音私信
                抖音个人主页  淘宝订单  淘宝购物车  位置  电量
              简称也认，「支付宝」「购物车」「定位」都能匹配上。
              ⚠️ 不含网易云、闹钟、锁屏——那些是操控不是查岗，
                 它们的工具照常保留，不受影响。

【其他配置项】
  interval_seconds        每项间隔，默认 5 秒
                          填太小前后两张图容易串台
  streaming               流式查岗，默认关
                          ※ 不是 API 的流式输出
                          关（推荐）：全查完 → 所有图一次性识图
                                      → 只问 AI 一次 → 发 1 条消息
                          开：每截一张就识一次、问一次、发一条，
                              查 4 项 = 4 条消息 + 4 次识图 + 4 次 AI
                              token 大概是关闭时的四倍
  suppress_other_tools    撤掉其他查看类工具的注入，默认开
                          这是省 token 的关键。网易云/闹钟/锁屏不受影响
  private_only            只在私聊查岗，默认开
                          群聊里主动播报你的支付宝账单不太妙
  hold_user_message       查岗期间按住你的新消息，默认开
  hold_max_seconds        最多按住多久，默认 600
  cooldown_seconds        冷却，默认 300 秒
                          查完这么久内不再查、也不再提示 AI，
                          免得它上瘾式连查。填 0 = 不冷却
  history_rounds          主动说话时带上最近几轮对话，默认 10
                          带人设 + 历史，免得人格分裂。0 = 只带人设
  vision_timeout_seconds  批量识图超时，默认 180
                          多张图一次识别比单张慢得多，别填太小
  marker                  暗号，默认 [查询用户手机APP]
                          改了这里，下面 hint 那句也要改成同一个
  hint                    注入给 AI 的那一条提示
                          留空 = 不注入，AI 就不知道自己能查岗
  round_prompt            流式模式每项的提示词
  final_prompt            一次性模式的总结提示词
  vision_batch_prompt     批量识图提示词，留空用内置的
  reply_template          主动说的那句话写进记忆的格式

【不用建新自动化】
整合查岗用的还是各功能原来的邮件主题（ASTRBOT_ALIPAY、
ASTRBOT_TAOBAO_CART……），你按前面章节建好的自动化直接就能用。
但填进 features 的项目，对应的自动化必须先建好，
不然那一项只会干等到超时。

【第一次开怎么试】
features 里只填「电量」一项。它最快、最不容易出错，
也不用解锁手机。等收到 AI 主动来找你说话，
再一项一项往上加。

【迟到的截图】
iPhone 回传截图时没法带「这是第几张」，插件只能按先后认领。
所以某一项超时后会留一张「迟到条」，之后到的第一张图
只在「不可能属于当前项目」时才丢（当前没人在等，
或者当前项目才发出去不到 8 秒）。迟到条自己也会过期作废，
不会误伤后面正常的截图。

【日志里怎么看】
  🕵️ 开始整合查岗，共 4 项：…（一次性）
  ⏱️ 第 N 号查岗请求（支付宝账单）已超时  ← 那一项没回来
  ⏸️ 查岗还没结束，先按住用户这条消息       ← 你插话了
  ▶️ 查岗结束，放行刚才按住的消息
  📨 查岗主动发言已发送
  🧠 已把查岗攒下的 5 条记录挂到本轮        ← 记忆插件这时才抄到
  ✅ 整合查岗结束

 配完之后
═══════════════════════════════════════════════════════

【必须重载插件】
插件配置改完，去 AstrBot 管理面板点插件的「重载」。
不重载的话新开的功能不生效，电量和位置的接口也挂不上。

【怎么跟 AI 说】
正常说话，不用记命令：
  放首晴天 / 放每日推荐 / 来点私人漫游 / 放我收藏的歌 / 暂停
  放我的摇滚歌单 / 来点睡前的（预设歌单，名字按你自己填的来）
  我手机还有多少电 / 看看我微信 / 我最近花了多少钱
  我最近看了什么视频 / 有人给我发抖音私信吗 / 看看我抖音主页
  我的快递到哪了 / 我购物车里有啥 / 我现在在哪
  明早七点半叫我起床 / 帮我锁屏

※ 整合查岗不在这里面——它是全主动的，只有 AI 自己会触发。
  你说「查岗」「看看我所有 App」都不会启动它。
  另外它开启后（suppress_other_tools 默认开），上面「看看我微信」
  「我最近花了多少钱」这类查看类的说法就不管用了，
  因为那些工具已经被撤掉了。放歌、闹钟、锁屏照常。

【手机要解锁亮屏】
打开 App、截图这些动作需要手机解锁亮屏，锁屏下只能截到锁屏画面。
锁屏、播放/暂停这两个锁屏状态下也能用。

【出问题按这个顺序查】
1. 去 iCloud 邮箱看有没有收到邮件
   没收到 → SMTP 配置问题，密码要用 App 专用密码，iCloud 端口必须 587
2. 收到了但手机没反应 → 自动化配错了，重点查：
   主题词有没有打错（全大写，是下划线不是减号）
   「运行前询问」有没有关掉
   「立即运行」有没有打开
3. 手机动了但 AI 说超时 → 回传配置的问题，重点查：
   image 那一行是不是选成了【文本】（必须是【文件】）
   URL 里的 IP 有没有写成 127.0.0.1（手机上那是手机自己）
   密钥有没有和插件配置里的完全一致

【想单独测一个自动化】
快捷指令 App 里点进那个自动化，右下角有播放按钮可以手动跑。
但播歌、闹钟这两个手动跑会失败（因为没有邮件正文），这是正常的，
它们只能靠 AI 触发来测。截图类、锁屏类可以放心手动测。

【经常超时】
插件配置里 timeout_seconds 调到 120，
同时把截图功能里的「等待」从 3 秒改成 5 秒。

 建议的配置顺序
═══════════════════════════════════════════════════════

1. 先配【锁定屏幕】——一个动作，最容易成功，用来验证邮件链路通不通
2. 通了配【打开微信并截图】——把截图那四步走一遍
3. 再配【查看电量】——把 JSON 回传走一遍
4. 剩下的按需配，每配完一个单独测一次
5. 都通了再考虑开【整合查岗】，features 里先只填「电量」试一次

别一次全配完再测，出问题不好找。
