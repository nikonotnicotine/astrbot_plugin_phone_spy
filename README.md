# iOS 快捷指令配置指南

本插件通过 **iCloud 邮件 + iOS 快捷指令自动化** 触发 iPhone 截屏。推荐搭配[屏幕查岗](https://github.com/nikonotnicotine/astrbot_plugin_screen_monitor )使用。

---

## 前置条件

- **iOS 18.4 或更新版本**（邮件自动化功能要求）
- **必须使用 iCloud 邮箱作为收件人**（形如 `你的名字@icloud.com`）
  - 为什么必须是 iCloud：因为 iOS 邮件自动化只对 iCloud 邮件的**推送**即时响应（几秒内到达）
  - QQ 邮箱、Gmail 等非 iCloud 邮箱，iPhone 需要**轮询**才能收到邮件，延迟 5-15 分钟
- 发件方可以是任何邮箱（QQ、163、Gmail、iCloud 都行），最简单的方案是 iCloud 自己给自己发

## 本地部署配置

**适用场景：** AstrBot 运行在家里的 Windows/Mac/Linux 电脑上，和 iPhone 在同一局域网内。

### 第一步：在 AstrBot 控制面板配置插件

打开 AstrBot 控制面板 → 插件管理 → 找到 `astrbot_plugin_phone_spy` → 点击配置。

按下表填写：

| 配置项 | 填什么 | 示例 | 说明 |
|--------|--------|------|------|
| `smtp_host` | SMTP 服务器地址 | `smtp.mail.me.com`（iCloud）<br>`smtp.qq.com`（QQ 邮箱）<br>`smtp.163.com`（163 邮箱） | 用哪个邮箱**发**触发邮件，就填对应的 SMTP 地址 |
| `smtp_port` | SMTP 端口 | `587`（iCloud 必须用 587）<br>`465`（QQ/163 用 465） | iCloud 必须 587，其他邮箱一般 465 |
| `smtp_user` | SMTP 登录账号 | `你的邮箱@icloud.com` | 完整邮箱地址（这个地址稍后要填进 iPhone 自动化的"发件人"条件） |
| `smtp_password` | SMTP 授权码 | `abcd-efgh-ijkl-mnop` | **不是登录密码！**<br>iCloud：到 appleid.apple.com → 安全 → App 专用密码（需先开启双重认证）<br>QQ 邮箱：设置 → 账户 → 开启 SMTP 后获取授权码 |
| `icloud_address` | 收件人 iCloud 邮箱 | `你的名字@icloud.com` | **必须是 iCloud 邮箱**，触发邮件发到这里，iPhone 收到后自动截屏<br>可以和 `smtp_user` 填成同一个地址（自己发给自己） |
| `webhook_port` | 接收服务端口 | `8080` | 插件在这个端口开 HTTP 服务等 iPhone 回传截图<br>若端口被占用请换一个（如 9001） |
| `webhook_path` | 接收路径 | `/phone/screenshot` | **只填路径**，不要填完整 URL<br>⚠️ 开头必须有 `/` |
| `webhook_secret` | 校验密钥 | 随机 16 位以上字符串 | 在终端执行 `openssl rand -hex 24` 生成一个<br>这个密钥稍后要填进 iPhone 快捷指令 |
| `vision_api_url` | 识图模型 API | `https://api.openai.com/v1/chat/completions` | OpenAI 兼容格式的视觉模型 API 地址 |
| `vision_api_key` | 识图模型密钥 | `sk-...` | 对应 API 的密钥 |
| `vision_model` | 识图模型名称 | `gpt-4o` | 必须是支持看图的模型（如 gpt-4o、gemini-2.0-flash-exp、qwen-vl-plus） |
| `timeout_seconds` | 超时时间（秒） | `90` | 从发邮件到收到截图的最长等待时间<br>正常 10-30 秒完成，建议留 60-120 |
| `forward_image` | 是否转发截图给你 | `false` | 开启后 AI 查岗时会把截图也发到聊天里 |
| `auto_fallback` | 手机失败时改查电脑 | `true` | 手机没响应时自动调用电脑查岗兜底（需安装 screen_monitor 插件） |

**配置完成后，点击"保存"并重新加载插件。**

---

### 第二步：在 iPhone 上创建快捷指令

#### 2.1 新建快捷指令（负责截图和上传）

1. 打开 **快捷指令 App** → 点右上角 `+` 新建
2. 按顺序添加以下动作：

   **动作 1：截屏**
   - 搜索并添加 **"截屏"** 动作（在"媒体"分类下）

   **动作 2：转换图片格式**
   - 搜索并添加 **"转换图像"**
   - 格式选择 **JPEG**
   - 质量设为 **0.5**（压缩以加快上传）

   **动作 3：上传到服务器**
   - 搜索并添加 **"获取 URL 内容"**
   - **URL** 填：`http://你电脑的局域网IP:8080/phone/screenshot`
     - 例如：`http://192.168.1.100:8080/phone/screenshot`
     - 如何查看电脑的局域网 IP：
       - Windows：`ipconfig` 看 IPv4 地址
       - Mac：系统设置 → 网络 → 看当前连接的 IP
       - Linux：`ip addr` 或 `ifconfig`
   - **方法** 改为 **POST**
   - **请求体** 选择 **"表单"**
   - 点击 **"添加新字段"** 或 `+` 号，添加两个字段：

     **字段 1（校验密钥）：**
     - **左边（字段名）**：填 `secret`（全小写，不要填中文"密钥"）
     - **右边（字段值）**：类型选 **"文本"**，内容填你在插件配置里设置的 `webhook_secret`
       - 例如：`a7f3k9m2q5x8w1z4`

     **字段 2（截图文件）：**
     - **左边（字段名）**：填 `image`（全小写）
     - **右边（字段值）**：类型选 **"文件"**，点击选择 **"转换后的图像"**（上一步转换的 JPEG）

3. 将快捷指令命名为 **"手机查岗截图"**
4. 点右上角"完成"保存

#### 2.2 新建邮件自动化（负责触发截图）

1. 打开 **快捷指令 App** → 底部点 **"自动化"** 标签
2. 点右上角 `+` → 选 **"个人自动化"**
3. 选择 **"邮件"** → **"收到新邮件时"**
4. 配置触发条件（**三个条件都要设置**）：
   - **发件人**：包含 → 填你在插件配置里设置的 `smtp_user`（发触发邮件的账号）
   - **主题**：包含 → 填 `PHONESPY_TRIGGER`（全大写）
   - **收件人**：包含 → 填你的 iCloud 邮箱地址
5. 点"下一步"
6. 点"添加操作" → 搜索并选择你刚创建的快捷指令 **"手机查岗截图"**
7. **⚠️ 重要：** 关闭"运行前询问"开关，确保 **"立即运行"** 开启
8. 点"完成"保存

---

### 第三步：测试

1. 确认 AstrBot 日志显示：`📡 截图接收服务已启动: http://0.0.0.0:8080/phone/screenshot`
2. 对 AI 说"看看我手机"
3. 预期流程：
   - 插件发送触发邮件 → iPhone 收到邮件（几秒内）
   - 邮件自动化触发 → 快捷指令运行 → 截屏 → 上传
   - 服务器收到截图 → 视觉模型分析 → AI 回复屏幕内容

**如果超时收不到截图：**
- 确认邮件是否到达 iCloud 邮箱（打开邮件 App 查看）
- 确认快捷指令的邮件自动化是否设置为 **"立即运行"**
- 确认 iPhone 和电脑在同一局域网，IP 地址填对了
- 用浏览器访问 `http://你的IP:8080/phone/screenshot`，应该返回 404 或 405（说明服务在运行）

### 第二步：配置 VPS 网络访问

#### 方案 A：Tailscale（推荐）

**优点：** 不需要开放公网端口，流量加密，无需维护 IP 白名单

**步骤：**

1. 在 VPS 和 iPhone 上都安装 Tailscale，加入同一个账户
2. 记下 Tailscale 分配给 VPS 的 IP（形如 `100.x.x.x`）
3. iPhone 快捷指令里的 URL 填：`http://100.x.x.x:9001/phone/screenshot`
4. VPS 防火墙**不需要**放行 9001 端口（Tailscale 走加密隧道）

#### 方案 B：公网 IP + 防火墙白名单

**优点：** 不需要额外软件，直接用公网 IP 访问

**步骤：**

1. **在服务商控制台配置安全组/防火墙**
   - 添加入站规则：
     - **协议**：TCP
     - **端口**：你配置的 `webhook_port`（如 9001）
     - **来源**：**只允许你 iPhone 所在网络的公网 IP**
       - 查看 iPhone 的公网 IP：用 iPhone 浏览器访问 `https://ip.sb` 或 `https://ifconfig.me`
       - ⚠️ **不要填 `0.0.0.0/0`**（会开放给全世界所有人）
   - 保存规则

2. **注意事项：**
   - 家庭宽带的公网 IP 可能会变化（通常几天到几周变一次）
   - IP 变化后需要手动更新防火墙规则
   - 如果觉得维护麻烦，建议用方案 A（Tailscale）

3. **为什么不建议直接开放 0.0.0.0/0？**
   - 公网上有大量自动扫描器，会持续向所有开放端口发请求
   - 虽然插件靠 `webhook_secret` 鉴权（不匹配返回 403），不会被轻易伪造
   - 但无谓的扫描流量会写满日志、消耗带宽，偶尔触发服务商告警
   - IP 白名单可以从源头阻断这些噪音

### 第四步：VPS 上测试连通性

在 VPS 终端执行：

```bash
curl -X POST http://127.0.0.1:9001/phone/screenshot \
  -F "secret=你的webhook_secret" \
  -F "image=@/tmp/test.jpg"
```

**预期结果：**
- 返回 `ok` 或 `200 OK`：成功
- 返回 `403 forbidden`：密钥不对，检查 `secret` 值
- 返回 `404 not found`：路径不对，检查 `webhook_path` 是否以 `/` 开头
- `Connection refused`：端口未放行或服务未启动

## 常见问题

### 1. 邮件会不会自动删除？

**不会。** 插件只通过 SMTP 发送触发邮件，不会登录 iCloud 读取、移动或删除邮件。触发邮件会一直留在收件箱，需要手动清理。

**建议：**
- 在 iCloud 邮件网页端建立规则，将主题包含 `PHONESPY_TRIGGER` 的邮件自动移到专用文件夹
- 先不要设置自动删除，确认自动化稳定后再定期清空文件夹

### 2. 为什么快捷指令报"密钥不匹配"？

**最常见原因：** 表单字段名填错了。

- ❌ 错误：字段名填成了"密钥"或"secret="
- ✅ 正确：字段名必须是 `secret`（小写），字段值才是密钥本身

检查方法：
- 打开快捷指令，点"获取 URL 内容"
- 展开"请求体"，确认有两个字段
- 第一个字段**左边**应该显示 `secret`（不是密钥值）
- 第一个字段**右边**才是密钥值（如 `a7f3k9m2q5x8w1z4`）

### 3. 超时时间设置成 60 秒，是不是要等 60 秒才发送？

**不是。** `timeout_seconds` 只是"最多等 60 秒"的意思，截图到达后会**立刻处理**，不会继续等。

正常流程：
- 邮件发出 → iPhone 收到（2-5 秒）→ 截屏上传（5-20 秒）→ 服务器立刻处理
- 总耗时通常 10-30 秒，远远不到 60 秒

只有当截图**真的没到**时，才会等到 60 秒超时。

### 4. VPS 的 `webhook_path` 到底怎么填？

**只填路径部分，不填完整 URL。**

- ❌ 错误：`/http://182.64.943.9:9001/phone/screenshot`
- ❌ 错误：`http://182.64.943.9:9001/phone/screenshot`
- ✅ 正确：`/phone/screenshot`

完整 URL 只在 iPhone 快捷指令里填，配置文件里只填路径。

### 5. 能否直接导入快捷指令？

**不能通过普通文件直接导入。** Apple 的快捷指令分享链接必须由 iPhone 上的"快捷指令" App 生成，尤其是"获取 URL 内容"的 `multipart/form-data` 文件字段，需要由 iOS 写入。

**建议：**
1. 按上面步骤手动创建一次（通常只需几分钟）
2. 创建后在 iPhone 上点"分享" → "复制 iCloud 链接"
3. 以后在其他设备打开这个链接就能导入
4. 导入后只需检查服务器地址、密钥是否正确

### 6. 内存会不会爆炸？

**正常使用下不会。** 插件已做限制：

- 单个请求体最大 **16 MB**
- 单张图片最大 **16 MB**
- 最多同时保留 **8 个**等待中的查岗请求
- 超时、成功和插件重载都会自动清理

iPhone JPEG 截图通常只有几百 KB 到几 MB，对 1-2 GB 的 VPS 压力很小。

### 7. iCloud 邮件存储会不会满？

**触发邮件本身很小**（几百字节），不会占用明显空间。插件不会把截图上传到 iCloud 邮箱，截图只在 VPS 内存里临时保存，分析完就释放。

## 安全建议

1. **`webhook_secret` 必须随机且足够长**（≥16 字符）
   ```bash
   openssl rand -hex 24
   ```

2. **保护 VPS 上的配置文件**（里面有密钥明文）
   ```bash
   chmod 600 data/config/astrbot_plugin_phone_spy_config.json
   ```

3. **VPS 部署时不要开放 0.0.0.0/0**
   - 用 Tailscale 或 IP 白名单限制访问
   - `webhook_secret` 是最后一道防线，但白名单能从源头阻断扫描流量

4. **定期检查 VPS 日志**
   - 如果看到大量 403 请求，说明有人在扫描你的端口
   - 考虑更换端口或启用 Tailscale
