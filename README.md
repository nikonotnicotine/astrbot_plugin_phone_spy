# 手机查岗 (Phone Spy)

让 AI 主动看你 iPhone 当前的屏幕。AI 想看时，插件给你的 iCloud 发一封邮件 → iPhone 收到后自动截屏 → 传回电脑 → 识图模型描述画面 → AI 拿到描述回复你。

---

## 先搞懂：这里有两个邮箱，作用完全不同

这是最容易搞混的地方，**先看懂这张图再去填配置**：

```
  ┌─ 发件方 (smtp_*) ─┐              ┌─ 收件方 (icloud_address) ─┐
  │  AstrBot 用它发信  │  ──邮件──▶   │  iPhone 上登录的 iCloud    │
  │  可以是任意邮箱     │              │  必须是 @icloud.com        │
  └───────────────────┘              └────────────┬──────────────┘
                                                   │ 触发快捷指令
                                                   ▼
                                              截屏 → 回传
```

- **发件方**只是"发一封信"这个动作，用哪家邮箱都行，**发信是秒发，不存在慢的问题**。
- **收件方必须是 iCloud**。因为 iOS 的邮件自动化只对 iCloud 的**推送**即时反应；如果收件箱是 QQ/Gmail，iPhone 要靠**轮询**去拉取，会延迟 5～15 分钟。

> **所以「QQ 邮件太慢」的担心是多余的** —— 慢的是收件方轮询，不是发件方。
> 而且你完全可以两边都用 iCloud：**自己发给自己**，这是最省事的方案，下面就按这个来。

---

## 一、填插件配置

在 AstrBot 面板 → 插件管理 → 手机查岗 → 配置。推荐的填法：

| 配置项 | 填什么 |
| --- | --- |
| `smtp_host` | `smtp.mail.me.com` ← 已是默认值，不用改 |
| `smtp_port` | `587` ← 已是默认值，不用改（iCloud 只支持 587） |
| `smtp_user` | 你的 iCloud 地址，如 `zhangsan@icloud.com` |
| `smtp_password` | **App 专用密码**（不是你的 Apple ID 密码！生成方法见下） |
| `icloud_address` | **同一个** iCloud 地址 `zhangsan@icloud.com` |
| `webhook_port` | `8080`（默认，端口冲突就换） |
| `webhook_path` | `/phone/screenshot`（默认，不用改） |
| `webhook_secret` | 自己编一串 16 位以上随机字符，如 `a7f3k9m2q5x8w1z4` |
| `vision_api_url` / `vision_api_key` / `vision_model` | 直接照抄你「电脑查岗」插件里已经填好的那三项 |

### 怎么生成 App 专用密码

iCloud 不允许第三方程序用你的 Apple ID 密码登录，必须单独生成一个：

1. 先确保 Apple ID 已开启**双重认证**（没开的话生成不了）
2. 浏览器打开 [account.apple.com](https://account.apple.com) → 登录
3. 「登录与安全」→「App 专用密码」→ 生成一个，名字随便写（如 `AstrBot`）
4. 把生成的那串 `xxxx-xxxx-xxxx-xxxx` 填进 `smtp_password`

> iCloud 有每天约 200 封的发信上限，日常查岗远远够用。

## 二、让 iPhone 能连到你的电脑

插件在你电脑上开了个端口等 iPhone 传图。iPhone 得能连上它。**按你的情况三选一**：

| 方案 | 适合 | 填什么地址 | 代价 |
| --- | --- | --- | --- |
| **同一个 WiFi** | 只在家里用 | 电脑的局域网 IP，如 `192.168.1.5` | 免费、无需装任何东西。**但你人一出门就失效** |
| **Tailscale** | 想随时随地都能用 | Tailscale 分配的 IP，如 `100.79.x.x` | 电脑和 iPhone 都要装，手机上要保持开启 |
| **公网 IP + 端口转发** | 电脑有公网 IP | 你的公网 IP | 要在路由器上做端口映射，且暴露在公网上 |

**关于你问的「手机上也要一直开着 Tailscale 吗」——是的，但没那么可怕：**

- iOS 上的 Tailscale 是一个 **VPN 描述文件**，装好后在后台常驻，不用每次手动打开
- 它不是那种全局代理，只接管 `100.x.x.x` 这个私有网段的流量，**不影响你正常上网、不走它的流量**
- 耗电很低，日常基本无感

**如果你只是在家里用，那就别折腾 Tailscale**，直接用同一个 WiFi + 局域网 IP 最简单。查看电脑局域网 IP：`Win + R` 输入 `cmd`，敲 `ipconfig`，看「IPv4 地址」。

## 三、在 iPhone 上建快捷指令

> 需要 **iOS 18.4 或更新版本**（邮件自动化是这个版本才有的）

### 3.1 先建一条快捷指令（负责截屏和上传）

打开「快捷指令」App → 右上角 `+`：

1. 加入「**截屏**」动作
2. 加入「**将图像转换为 JPEG**」，质量拉到 **0.5**（压缩一下，传得快）
3. 加入「**获取 URL 内容**」：
   - URL 填：`http://<第二步选定的地址>:8080/phone/screenshot`
     （例如 `http://192.168.1.5:8080/phone/screenshot`）
   - 「方法」改成 **POST**
   - 「请求体」选 **表单**
   - 在表单里加两个字段：
     - `secret` → 类型**文本** → 内容填你配置里那串 `webhook_secret`
     - `image` → 类型**文件** → 选上一步转换出来的 JPEG
4. 命名为「**手机查岗截图**」，保存

### 3.2 再建一条自动化（负责在收到邮件时触发它）

「快捷指令」App → 底部「**自动化**」→ `+` → 「**个人自动化**」→ 选「**邮件**」：

- **发件人**：包含 → 填你的 `smtp_user`（即 `zhangsan@icloud.com`）
- **主题**：包含 → 填 `PHONESPY_TRIGGER`
- **收件人**：包含 → 填你的 `icloud_address`
- 往下把「**立即运行**」打开 ⚠️ **这步最关键**，默认是「运行前询问」，不打开的话每次都要你手动点确认，等于没用
- 下一步选择刚才那条「手机查岗截图」，保存

---

## 四、测一下

1. AstrBot 面板里确认插件已启用，日志里能看到
   `📡 截图接收服务已启动: http://0.0.0.0:8080/phone/screenshot`
2. 先单独测一下 iPhone 能不能连上电脑 —— 在电脑上跑：
   ```bash
   curl -X POST "http://<你的地址>:8080/phone/screenshot" -F "secret=<你的密钥>" -F "image=@随便一张图.jpg"
   ```
   返回 `ok` 就说明服务正常。
3. 对 AI 说「看看我手机在干嘛」，正常的话十几秒内就会收到画面描述。

## 常见问题

**一直提示超时收不到截图**
- 邮件到你 iCloud 了吗？没到 → 检查 `smtp_password` 是不是填成了 Apple ID 密码（要填 App 专用密码）
- 邮件到了但手机没反应 → 自动化的「**立即运行**」没打开，这是最常见的原因
- 手机有反应但传不回来 → iPhone 连不上你电脑，回到第二步；注意 **Windows 防火墙**可能拦了 8080 端口，需要放行

**提示"插件配置不完整"**
说明 `smtp_user` / `smtp_password` / `icloud_address` / `webhook_secret` 有没填的，面板里补上。

**手机查岗失败会怎样**
如果 `auto_fallback` 开着（默认开），会自动改成查你的电脑屏幕（需要装了「电脑查岗」screen_monitor 插件），AI 会知道"手机没看成，这是电脑的画面"。两个都失败才会告诉 AI 你可能在忙或在睡觉。

**能不能不用 iCloud**
收件方不行，必须 iCloud，这是 iOS 邮件自动化的限制。发件方随意。

## 隐私提醒

这个插件会把你手机屏幕的截图发给第三方识图 API。屏幕上如果有聊天记录、验证码、账号信息，都会一并传过去。`webhook_secret` 也务必设置，否则任何能访问到那个端口的人都能往里塞图片。
