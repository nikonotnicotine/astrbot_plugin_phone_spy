# iOS 快捷指令配置指南

本插件通过 **iCloud 邮件 + iOS 快捷指令自动化** 触发 iPhone 截屏。以下是完整的配置流程。

## 前置条件

- **iOS 18.4 或更新版本**（邮件自动化功能要求）
- **必须使用 iCloud 邮箱**（形如 `你的名字@icloud.com`）作为收件人。QQ 邮箱等非 iCloud 邮箱有 5-15 分钟的邮件轮询延迟，会导致触发极慢
- 服务器能通过 **公网 IP 或 Tailscale** 访问插件的 HTTP 接收服务

## 第一步：配置插件

在 AstrBot 控制台的插件设置中，填写：

| 字段 | 说明 |
| --- | --- |
| `smtp_host` | 发送触发邮件用的 SMTP 服务器，如 `smtp.qq.com` |
| `smtp_port` | 465（SSL）或 587（STARTTLS） |
| `smtp_user` | SMTP 账号（完整邮箱地址） |
| `smtp_password` | **SMTP 授权码/应用专用密码**，不是登录密码 |
| `icloud_address` | 你的 iCloud 邮箱（如 `你的名字@icloud.com`），触发邮件发到这里。**必须是 iCloud 邮箱**，不能填 QQ/Gmail |
| `webhook_port` | 截图接收服务端口，默认 8080 |
| `webhook_path` | 接收路径，默认 `/phone/screenshot` |
| `webhook_secret` | **必填**，≥16 字符随机字符串。快捷指令 POST 时需携带相同的 secret |
| `vision_api_url` / `vision_api_key` / `vision_model` | OpenAI 兼容的视觉模型 API |

## 第二步：创建快捷指令（截图并上传）

1. 打开 **快捷指令 App**，点击 `+` 新建快捷指令
2. 添加 **"截屏"** 动作（位于"媒体"分类）
3. 添加 **"将图像转换为 JPEG"** 动作，质量设为 0.5（压缩以加快上传）
4. 添加 **"获取 URL 内容"** 动作：
   - URL 填入：`http://<服务器地址>:<webhook_port><webhook_path>`
   - 方法改为 **POST**
   - 请求体选择 **"表单"**
5. 在请求体表单中添加两个字段（快捷指令中 POST 表单字段以键值对形式添加）：
   - `secret`：值填 `文本` 类型，内容为插件配置的 `webhook_secret`
   - `image`：值填 **"文件"** 类型，内容选择上一步转换后的 JPEG 图像
6. 添加 **"退出快捷指令"** 动作（可选，避免继续执行后续动作）
7. 将这个快捷指令命名为 **"手机查岗截图"**

> 注意：快捷指令的"获取 URL 内容"在 iOS 18.4+ 支持 POST 表单上传文件。如果 iOS 版本较低，可能只支持文本字段，此时需要将图片 base64 编码后以文本方式提交（插件接收端已兼容 base64 文本）。

## 第三步：配置邮件自动化

1. 打开 **快捷指令 App** → 底部 **"自动化"** 标签
2. 点击 `+` → **"个人自动化"**
3. 选择 **"邮件"** → **"收到新邮件"**
4. 配置触发条件（三个都要设置）：
   - **发件人**：包含插件的 `smtp_user`（即发送触发邮件的账号）
   - **主题**：包含 `PHONESPY_TRIGGER`
   - **收件人**：包含你的 iCloud 邮箱地址
5. 设置 **立即运行**（不要关闭"立即运行"开关，否则必须手动确认才能运行）
6. 选择上一步创建的快捷指令 **"手机查岗截图"**
7. 保存自动化

## 第四步：服务器网络可达性

- **公网 IP**: 插件监听 `0.0.0.0:webhook_port`，如果服务器有公网 IP，在路由器/防火墙放行该端口即可
- **Tailscale**: 两台设备都装上 Tailscale，服务器地址填 Tailscale 分配的 IP（如 `100.x.x.x`），无需公网配置
- **注意**: 如果服务器在云上且有防火墙规则（如阿里云安全组、腾讯云防火墙），需要放行 `webhook_port` 的入站 TCP

## 第五步：测试

1. 在 AstrBot 控制台确认插件已激活，日志看到"📡 截图接收服务已启动: http://0.0.0.0:8080/phone/screenshot"
2. 对 AI 说"看看我手机"（或触发 `check_phone_screen` 工具）
3. 预期流程：
   - 插件发送触发邮件到你的 iCloud 邮箱
   - iPhone 收到邮件 → 快捷指令自动化立即运行 → 截屏 → POST 回服务器
   - 插件收到截图 → 视觉模型分析 → AI 回复屏幕内容描述

## 常见问题

### 一直超时收不到截图？

- 确认邮件是否到达 iCloud 邮箱（如果邮件延迟很久才到，说明收件人不是 iCloud 邮箱）
- 确认快捷指令的邮件自动化是否设置为 **立即运行**
- 确认 iPhone 熄屏状态下快捷指令能否运行（锁屏可能阻止截屏）
- 用浏览器手动 POST 测试接收服务是否可达：
  ```bash
  curl -X POST "http://<服务器地址>:<端口><路径>" \
    -F "secret=<你的密钥>" \
    -F "image=@test.jpg"
  ```

### 快捷指令报错"无法连接到服务器"？

- 检查服务器地址是否正确（公网 IP / Tailscale IP）
- 检查 `webhook_port` 是否放行
- 检查插件是否已激活

### 为什么不建议用 QQ 邮箱作为收件人？

因为 QQ 邮箱不是 iCloud 邮箱，iCloud 邮件自动化依赖 iCloud 服务器对邮件的 **推送**，而非 iCloud 邮箱的收件只能靠轮询（5-15 分钟延迟）。因此收件人**必须**是 iCloud 邮箱。
