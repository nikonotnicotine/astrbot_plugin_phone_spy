# iOS 快捷指令配置指南

## 前置要求

- iPhone 需要 **iOS 18.4 或更高版本**
- iPhone 上必须添加并登录 **iCloud 邮箱账户**（设置 → 邮件 → 账户）
- 插件服务器需要能从手机网络访问到（公网 IP 或 Tailscale 内网穿透）

---

## 第一步：在 iPhone 上添加 iCloud 邮件账户

1. 打开「设置」→「邮件」→「账户」→「添加账户」
2. 选择「iCloud」，登录你的 Apple ID
3. 确认「邮件」开关已打开

---

## 第二步：创建快捷指令

打开「快捷指令」App → 底部「快捷指令」标签 → 右上角 ＋ 号

按顺序添加以下动作：

### 动作 1：截取当前屏幕
- 搜索「截屏」→ 选择「截取当前屏幕」
- 变量名：`屏幕截图`

### 动作 2：将图像转换为 JPEG
- 搜索「转换图像」→ 选择「将图像转换」
- 输入：`屏幕截图`
- 格式：**JPEG**
- 质量：**50%**（减小体积，加快上传）

### 动作 3：POST 截图到服务器
- 搜索「获取 URL 的内容」→ 选择「获取 URL 的内容」
- 方法：**POST**
- URL：`http://你的服务器IP:8080/phone/screenshot`
  - 替换为插件配置中的 `webhook_port` 和 `webhook_path`
  - 例：`http://123.45.67.89:8080/phone/screenshot`
- 请求正文类型：**表单**
- 添加字段：
  - 键：`secret`，值：插件配置中的 `webhook_secret`
  - 键：`image`，值：上一步转换好的 JPEG 图像（点击「变量」选择）

### 动作 4：从收件箱删除触发邮件
- 搜索「过滤邮件」→ 选择「过滤邮件」
- 账户：你的 iCloud 邮箱
- 主题包含：`PHONESPY`
- 然后添加「移除邮件」→ 选择「移除邮件」，输入上一步过滤的邮件
- 移至：**已删除**

快捷指令命名为「手机查岗」或任意名称，**保存**。

---

## 第三步：创建自动化

打开「快捷指令」App → 底部「自动化」标签 → 右上角 ＋ 号

1. 选择「新建个人自动化」
2. 向下滚动找到「电子邮件」，点击选择
3. 配置触发条件：
   - **发件人**：填插件配置中的 `smtp_user`（如 `bot@qq.com`）
   - **主题包含**：`PHONESPY`
   - **收件人**：你的 iCloud 邮箱地址
4. 点击「下一步」
5. 添加动作：选择「运行快捷指令」→ 选择刚才创建的「手机查岗」快捷指令
6. 点击「下一步」
7. **关键设置**：将「运行前询问」关闭，改为「**立即运行**」
8. 「完成」保存

---

## 注意事项

| 项目 | 说明 |
|------|------|
| 邮箱必须用 iCloud | QQ/Gmail/163 在 iOS 上是定时拉取，延迟 5-15 分钟，无法实时触发 |
| 「立即运行」必须手动开启 | 默认是「运行前询问」，自动化不会静默执行 |
| 网络可达性 | 手机（蜂窝/WiFi）需能 HTTP 访问服务器的 webhook 端口 |
| HTTPS 推荐 | 公网部署时建议用 Nginx 反代 + HTTPS，防止 secret 明文传输 |
| iOS 版本 | iOS 18.4+ 才支持电子邮件触发的「立即运行」模式 |

---

## 测试方法

1. 确认 AstrBot 已加载插件且接收端口正常监听
2. 手动给 iCloud 邮箱发一封主题含 `PHONESPY` 的邮件（发件人必须是配置的 `smtp_user`）
3. iPhone 应在几秒内自动截屏并 POST 到服务器
4. 服务器日志应出现「收到手机截图」字样

---

## 排查常见问题

**自动化没有触发**
- 确认收件人、发件人、主题三个条件都匹配
- 确认「自动化」页面该条目的运行方式是「立即运行」而非「运行前询问」
- 确认 iCloud 邮箱账户已在「邮件」里登录

**截图上传失败（HTTP 超时）**
- 手机网络是否能访问服务器 IP 和端口
- 防火墙/NAT 是否放行了 `webhook_port`
- 尝试在手机 Safari 访问 `http://服务器IP:端口/` 看是否有响应

**secret 校验失败（服务器日志显示 403）**
- 快捷指令里 `secret` 字段的值和插件配置 `webhook_secret` 是否完全一致
- 注意前后空格
